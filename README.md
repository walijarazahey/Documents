
# HR-Analysis

HR Employee Attrition Analysis using Python

## Description
This project analyzes employee attrition data to find key factors that cause employees to leave.
It includes data cleaning, visualization, and basic insights using pandas, numpy, matplotlib, seaborn, and sklearn.

## Tech Stack
- Python
- pandas, numpy
- matplotlib, seaborn
- scikit-learn

## How to Run
1. Clone the repo
2. Install dependencies: `pip install pandas numpy matplotlib seaborn scikit-learn`
3. Run the file: `python HR-Analysis.py`
